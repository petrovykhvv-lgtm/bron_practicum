# design.md — визуальная система Verde Marea

Характер: спокойно, тепло, по-ресторанному. Матовое стекло поверх мягкой «сцены» из зелёных и золотых сфер, крупные засечные заголовки с курсивным акцентом, капсульные кнопки, чипы с круглыми золотыми иконками. Референсы: стеклянные карточки на атмосферном фоне.

Единый источник токенов — `:root` в [src/app/globals.css](src/app/globals.css); Tailwind получает их через `@theme`. Цвета и радиусы в компонентах задаются только токенами.

## 1. Палитра

Бренд (неизменные):

| Токен | Значение | Роль |
|---|---|---|
| `--vm-green` | `#1F4D3A` | основной: кнопки, активные элементы, акцентное слово заголовка |
| `--vm-gold` | `#C7A76C` | акцент: точки, линии, иконки, декоративная сфера |
| `--vm-cream` | `#F5F1E8` | фон, текст на зелёном |
| `--vm-ink` | `#1B1B1B` | основной текст |

Производные:

| Токен | Значение | Роль |
|---|---|---|
| `--vm-green-hover` / `--vm-green-soft` | `#183C2D` / `#2B6A51` | hover кнопки / светлый край градиента кнопки |
| `--vm-green-tint` | `#E3ECE6` | мягкий фон бейджей и hover |
| `--vm-gold-tint` | `#F2E9D6` | бейдж «Ожидает», непрочитанное, предупреждение |
| `--vm-gold-ink` | `#7A5F26` | золото для **текста** на светлом (метки «eyebrow»); обычное золото для текста не используется |
| `--vm-neutral-tint` | `#ECE9E1` | конечные и неактивные состояния: «Отменена», закрытое окно, «Нет» |
| `--vm-muted` | `#5E5B54` | вторичный текст |
| `--vm-danger` / `--vm-danger-tint` | `#9B3B2E` / `#F5E1DD` | ошибки, отмена, «Не пришёл» |
| `--vm-glass` / `--vm-glass-strong` | белый 62% / 82% | стекло карточек / стекло шапки и навигации |
| `--vm-glass-edge`, `--vm-hairline` | белый 78%, зелёный 14% | светлая кромка стекла, тонкие разделители |
| `--vm-surface`, `--vm-line` | `#FFFFFF`, `#DDD6C6` | сплошная поверхность, границы |

Градиенты: `--gradient-cta` (зелёный, кнопки и круглые иконки), `--gradient-gold` (золотые круги иконок).

## 2. Шрифты

- Заголовки: **Cormorant Garamond** (600/700), запасной Georgia. Включены «лайнинг» цифры (`lining-nums`), иначе «1» читается как «I».
- Текст и интерфейс: **Manrope** (400–600), запасной system-ui.

| Токен/класс | Размер | Шрифт |
|---|---|---|
| `.vm-title` | 36–52 (clamp) | Cormorant 700, `<em>` — курсив 600 зелёным (акцентное слово) |
| Заголовок главной | 44–76 (clamp) | то же |
| `h2` секции | 28–32 | Cormorant 600 |
| `.vm-eyebrow` | 12, капс, трекинг 0.16em | Manrope 700, `--vm-gold-ink`, слева золотая точка |
| `.vm-lead` | 18 | Manrope, `--vm-muted` |
| текст | 16 / 1.55 | Manrope 400 |
| малый и подписи | 14 / 12 | Manrope 500 |

## 3. Сцена и стекло

- **Сцена** (общая для гостя и админки): на `html` — кремовый фон, золотое свечение справа сверху, зелёная дымка слева снизу. Две фиксированные сферы (`body::before` золотая, `body::after` зелёная) лежат между фоном и контентом; они декоративны и не несут информации.
- **Стекло** (`.vm-glass`, `.vm-card`): фон `--vm-glass`, `backdrop-filter: blur(18px) saturate(1.25)`, светлая кромка, тень `--shadow-glass`. Если браузер не поддерживает blur, фон становится почти непрозрачным (94%), читаемость не страдает.
- **Шапка** — парящая стеклянная капсула (`.vm-header`), прилипает к верху; админские разделы — такая же стеклянная панель под ней.
- Радиусы: `--r-sm` 8 (мелкие), `--r-md` 14 (поля, чипы, уведомления), `--r-lg` 24 (карточки), `--r-xl` 32 (hero), `--r-pill` (кнопки, бейджи, шапка).
- Отступы: 4, 8, 12, 16, 24, 32, 48, 64. Контейнер 1120, поля 16 / 32.

## 4. Состояния (одни для всех интерактивных элементов)

| Состояние | Правило |
|---|---|
| hover | кнопка primary темнее (`--vm-green-hover`), secondary заливается `--vm-green-tint`, строки списков подсвечиваются |
| focus-visible | кольцо 2px `--vm-gold`; у полей дополнительно золотой ореол 3px |
| active | primary сдвигается на 1px вниз |
| disabled | непрозрачность 50%, `not-allowed`, без hover |
| error | граница поля и подпись `--vm-danger` под полем; баннер `Notice` kind=error с `role="alert"` |
| loading | кнопка блокируется, внутри спиннер `.vm-spinner` и глагол («Отправляем…»); короткие запросы — `InlineLoading`; скелетоны `.vm-skeleton` есть в стилях, но общего `loading.tsx` нет (он превращает редиректы защищённых страниц в 200 с meta refresh) |
| empty | `EmptyState`: золотая иконка, заголовок, пояснение «что делать», кнопка следующего шага |
| ошибка страницы / 404 | `error.tsx` и `not-found.tsx` на том же `EmptyState` |
| подтверждение | `ConfirmDialog` (нативный `<dialog>`: фокус заперт, Escape отменяет); необратимые действия красные (`vm-btn-danger-outline`) и отдельной группой |

Анимации ≤ 200 мс; при `prefers-reduced-motion` отключаются (включая скелетоны и спиннеры). Минимальная область нажатия 44px (малые кнопки `.vm-btn-sm` — 36px в плотных таблицах и карточках).

## 5. Компоненты

Общие примитивы: [src/components/ui](src/components/ui) — `Icon`, `Notice`, `EmptyState`, `PageHeader`, `Chip`, `Loading`, `NavLinks`; классы в `globals.css`.

- **Кнопки**: всегда капсула. `vm-btn-primary` — зелёный градиент, кремовый текст, на экране одна; `vm-btn-secondary` — стекло с зелёной рамкой; `vm-btn-danger` — для необратимого, с подтверждением; `vm-btn-sm` — компактная.
- **Форма**: метка над полем (Manrope 600), поле `.vm-input` (высота 46, радиус 14, белое 85%), подсказка `.vm-hint`, ошибка `.vm-error`. Выбор даты и времени — капсулы-«радио» (`role="radio"`), выбранная — primary. Шаги формы бронирования нумеруются зелёными кругами.
- **Карточка**: стекло, внутренний отступ 24 (в плотных списках 16–20). Карточка брони: дата и время крупным засечным, чипы «Гостей» и «Стол», бейдж статуса, действия справа.
- **Чип**: круг-иконка с золотым градиентом + подпись-метка и значение (`Chip`). Используется для фактов: гости, стол, дата.
- **Список и таблица**: на десктопе строки-сетка с шапкой `.vm-table-head`, разделители `--vm-hairline`, hover `.vm-row`; на мобильном строка превращается в карточку без горизонтального скролла. Фильтры — над списком; быстрые фильтры — капсулы.
- **Бейджи статусов** (капсула, точка слева, всегда с текстом):

| Статус | Подпись | Фон | Текст / точка |
|---|---|---|---|
| `pending` | Ожидает | `--vm-gold-tint` | ink / gold |
| `confirmed` | Подтверждена | `--vm-green-tint` | green |
| `cancelled` | Отменена | `--vm-neutral-tint` | muted |
| `completed` | Завершена | `--vm-green` | cream / gold |
| `no_show` | Не пришёл | `--vm-danger-tint` | danger |

- **Уведомление-баннер** (`Notice`): стекло, цветная полоса слева 4px и иконка; `success` — зелёная, `info` — золотая, `warn` — золотой оттенок, `error` — красный оттенок. Внутренние уведомления гостя — карточки с круглой иконкой по типу; непрочитанное на `--vm-gold-tint`.
- **Навигация** (`NavLinks`): капсулы; активный пункт — зелёная капсула с кремовым текстом (`aria-current="page"`). Одна и та же навигация в шапке и в разделах админки; на ширине меньше 1280 шапка сворачивается в «Меню».

## 6. Как гость и админка выглядят одним продуктом

| Что повторяется | Где |
|---|---|
| Сцена и стеклянные карточки | все экраны |
| `PageHeader`: eyebrow + заголовок с курсивным акцентом | гость: «Мои *брони*», «Забронировать *стол*»; админ: «Все *брони*», «Окна *записи*» |
| Чипы «Гость / Стол» | «Мои брони» и очередь заявок админа |
| Бейджи статусов | «Мои брони», список броней, история |
| `Notice` и `EmptyState` | все списки и сообщения обоих контуров |
| Капсулы навигации | шапка и разделы админки |

Отличия админки сознательные: вторая стеклянная панель с разделами, бейдж «Ваша роль», более плотные строки и компактные кнопки. Цвета и компоненты те же.

## 7. Контраст (проверено расчётом по WCAG)

Стекло считается как белое 62% поверх крема. Даже под самой тёмной частью зелёной сферы стекло остаётся светлым (расчётный худший случай: `muted` на нём ≈ 5.2:1).

| Пара | Контраст | Вывод |
|---|---|---|
| ink на фоне / на стекле | 15.3 / 16.5 | ок |
| muted на стекле / на кремовом | 6.5 / 6.0 | ок |
| green на стекле | 9.4 | ок |
| cream на green (кнопка, активная навигация, «Завершена») | 8.5 | ок |
| cream на светлом краю градиента кнопки `#2F7358` | 5.0 | ок |
| gold-ink на стекле / на кремовом (eyebrow) | 5.8 / 5.3 | ок |
| gold на кремовом | 2.0 | не для текста (только линии, точки, иконки) |
| gold на green | 4.2 | только крупный текст и декор |
| danger на danger-tint / на стекле | 5.5 / 6.7 | ок |
| бейджи: confirmed 8.0, pending 14.3, cancelled 5.6, no_show 5.5 | — | ок |
| белая иконка на золотом круге | 3.2 | декор, значение дублируется текстом |

## 8. Доступность

- Полная навигация с клавиатуры, видимый focus, `aria-current` в навигации, `role="radio"` у выбора даты и времени, `role="alert"`/`status` у сообщений.
- У полей связанные метки; ошибки и подсказки привязаны через `aria-describedby`.
- Состояние никогда не передаётся только цветом: у бейджей и уведомлений есть текст.
- Декоративные иконки и сферы скрыты от скринридеров.
